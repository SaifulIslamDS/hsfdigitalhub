# Third-party components & distribution review

The Design Studio source package supplied by HSF includes Fabric.js 5.3.0 (reported MIT), jsPDF 2.5.1 (reported MIT), Lucide icon vectors (reported ISC), and embedded Poppins, Playfair Display, and Hind Siliguri font assets (reported Open Font License). These statements originate in the HSF Design Studio handover and must be confirmed against the relevant upstream licences and redistributed notices before external sharing. This repository integration does not independently certify licence compliance, nor extract or redistribute standalone font files.

Do not remove upstream copyright notices from vendored JavaScript or icon sources. Do not assume a web access gate makes the public GitHub source private.
