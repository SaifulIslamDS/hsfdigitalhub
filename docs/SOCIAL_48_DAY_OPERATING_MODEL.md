## Daily model

| Window | Stream | Role |
|---|---|---|
| Around 9:00–10:00 AM | **HSF in Action** | FIELD / MOMENT / EVENT / OBS / HSF when relevant |
| Around 4:00–5:00 PM | **HSF Knowledge & Awareness** | One locked P01–P48 core post |

## Core rhythm

Each of the 24 themes occupies two consecutive days:

**Day A — Issue**  
**Day B — Resolution**

The complete core cycle therefore requires 48 publishing days.

The 3 Standard + 1 Special Engagement rhythm remains a format rule across P01–P48. It does not alter the one-core-post-per-day cadence.

## Morning rule

The morning slot is available but not compulsory.

Before publishing, ask:

**Is it real? → Is it useful? → Is it safe? → Is it sufficiently different? → Is evidence available? → Is publication better than silence?**

If an important answer is no, replace or skip the planned morning item.
