# Brand Alignment Note — September 2026 Social Pilot

The September 2026 two-window social publishing pilot does **not** require a Brand Identity version increment.

**Brand Identity & Social Design System v2.2 remains the governing visual baseline.**

It already supports:

- Core vs Overlay streams;
- OBS / HSF / FIELD / EVENT / MOMENT roles;
- authentic HSF photography;
- evidence/source treatment;
- safeguarding and privacy;
- Album = Documentation;
- Carousel = Storytelling;
- Moment = Human Presence;
- existing HSF palette selection by programme/purpose;
- internal overlay naming and production workflow.

No new palette, logo treatment, typography rule or mandatory visual family is introduced by this pilot.

A future Brand Guide v2.3 should be considered only if HSF later approves material visual-system changes such as platform-native rules, formal image-density rules, dedicated `HSF in Action` layouts, new campaign-set governance or a stable new Brand Design Stack.
