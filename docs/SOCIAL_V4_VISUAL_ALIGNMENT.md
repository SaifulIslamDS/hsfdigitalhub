# Social Communication v4.0 Candidate: Visual Production Alignment

**Status: proposed operating alignment, NOT a revision to Brand Identity v2.3 or Brand Stack v3.1.0.**

Existing authorised palettes, logo, naming, typography and six standard production ratios remain unchanged. The Brand Design Stack v3.1.0 is still a production candidate; its approved identity parts and 16 content-family policy may be adapted subject to manual visual QA, particularly Adobe Illustrator 2022 compatibility.

| v4.0 content | Existing design/asset family | QA emphasis |
|---|---|---|
| Field and authentic moment | Programme Story / Human Story / album / photo-led | No synthetic documentary claims; original media rights and consent |
| Case study | Human Story / 8-slide carousel | Attribution, timeline, appropriate context and anonymisation |
| Progress/success | Impact Number / Dashboard / Report | Baseline, measurement interval, comparator, caveats |
| Challenge-response | Programme Story / Guide / timeline | Acknowledge unresolved outcomes |
| Issue → Resolution | Existing paired visual system; awareness and practical guide | Historical references preserved without fixed order |
| KDI statistics | Impact Number / Dashboard / Report Publication / data carousel | Source footer, units, axes, visual scaling, method |
| Institutional/observance/engagement | Existing HSF / Event / Partnership / Volunteer / Reel systems | Genuine relationship status and accessible layout |

The stream label is editorial metadata, **not a separate HSF logo or palette**. Use photography first where ethical and suitable; infographics when statistics genuinely need visual explanation. Never place chart information outside readable cropping zones. If an asset family is missing, adapt approved masters and log the gap, rather than mislabel the asset stack as certified for v4.0.
