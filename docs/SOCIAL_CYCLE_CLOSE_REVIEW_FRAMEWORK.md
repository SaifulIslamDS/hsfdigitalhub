# HSF Social Communication — 48-Day Cycle Close Review Framework

**Purpose:** convert communication performance into institutional learning and a management decision for the next cycle.

## 1. Close the record
- confirm P01–P48 publication status;
- confirm 24 Issue–Resolution pairs;
- verify morning overlays actually published;
- record substitutions/skips;
- complete links, evidence and safeguarding fields;
- freeze/archive the completed tracker.

## 2. Core performance
Review:
- core posts published / 48;
- theme pairs completed / 24;
- Special Engagement posts completed / 12;
- reach and meaningful engagement;
- shares and saves;
- useful audience responses;
- performance by theme and format.

## 3. HSF in Action performance
Review:
- FIELD / MOMENT / EVENT / OBS / HSF counts;
- planned vs published morning slots;
- substitutions/skips and reasons;
- authenticity and repetition;
- safeguarding/privacy issues;
- evidence quality;
- production effort.

## 4. Programme representation
Assess public visibility across:
- E4BL;
- A2PHC;
- Climate Action;
- Women/Girls/Rights;
- Humanitarian/Social Protection;
- Livelihood;
- Institutional/Volunteer/Partnership.

Balance should be interpreted against real programme activity, not forced into equal quotas.

## 5. Theme learning decision
For every theme select:

**Retain / Refresh / Merge / Split / Retire**

Record why.

## 6. Management decision
Use:

**Measure → Interpret → Learn → Adapt → Approve**

Cycle 2 should be designed from evidence and priorities, not copied automatically.
