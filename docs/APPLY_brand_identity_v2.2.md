## Scope
This focused update aligns `brand_identity_master_guide.html` with `social_communication_plan.html` v3.2 while preserving the existing HSF visual backbone and the underlying v2.0 production stack.

- Brand guide version updated from v2.1 to v2.2.
- Added explicit Core (P01–P48) vs Special Communication Overlay architecture.
- Added OBS / HSF / FIELD / EVENT / MOMENT visual-role mapping.
- Preserved the 16 reusable content families and 600-template production inventory.
- Added observance/national-day, Foundation Day, photo album and HSF Moment rules.
- Added Field Activity, Event Photo Story and Institutional Memory carousel structures.
- Strengthened field/event/photo safeguarding and privacy checks.
- Updated the production decision model and pre-export checklist.
- Updated Knowledge Hub index metadata for the Brand Guide to v2.2.

## Not changed

- Evergreen master identity and four controlled expressions.
- Typography system.
- Six standardized production formats.
- Existing 600 editable SVG production-template inventory.
- Netlify PIN gate, environment configuration, routing or deployment security.
- The Social Communication Plan v3.2 48-post core sequence.

## Version boundary
The Brand Guide is now v2.2. The underlying `HSF Flexible Brand Identity System v2.0` and `HSF Final Brand Design Stack v2.0` remain documented as the source production stack; this update does not claim to regenerate the 600 SVG masters.
