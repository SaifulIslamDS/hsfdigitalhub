# HSF Digital Transformation Knowledge Hub v1.0.0

First stable institutional release.

This release includes:
- six connected master documents;
- responsive document navigation;
- website and editorial governance;
- Impact, Monitoring, Evaluation, Accountability & Learning framework;
- Figma-style website redesign concepts;
- whole-site Netlify Edge PIN protection;
- PIN visibility control;
- 12-hour signed access session;
- rate-limited PIN attempts;
- noindex/no-store protection.

The Knowledge Hub is a living institutional reference platform. Additional HSF documents, policies, SOPs, planning frameworks, training resources, research, and implementation guidance may be added over time.
