# Deploy to Netlify

This is a no-build static website.

## Manual deploy
1. Unzip this package.
2. Confirm `index.html` is at the root.
3. Drag the full folder to Netlify's manual deploy area.

## Git deploy
- Build command: leave empty.
- Publish directory: `.`
- `netlify.toml` is included.

Clean aliases are available:
- `/institutional-framework`
- `/social-communication`
- `/erp-overview`
- `/brand-design`
