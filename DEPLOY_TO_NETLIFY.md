# Deploy to Netlify

This is a no-build static website.

## Manual deploy
1. Unzip the package.
2. Confirm `index.html` is at the root.
3. Drag the whole folder into Netlify manual deploy.

## Git deploy
- Build command: leave empty.
- Publish directory: `.`
- `netlify.toml` and `_redirects` are included.

Clean aliases:
- `/institutional-framework`
- `/social-communication`
- `/erp-overview`
- `/brand-design`
