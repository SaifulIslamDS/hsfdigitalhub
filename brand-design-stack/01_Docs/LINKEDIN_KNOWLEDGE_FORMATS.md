# LinkedIn Knowledge Formats

LinkedIn is treated as HSF's institutional learning/evidence channel, not only as a single-image feed.

Included systems:
- Photo post up to 4:5 working master
- Multi-photo story
- Document / PDF carousel
- Project overview document
- Report brief
- Case study
- 16:9 slide deck masters
- A4 one-page fact sheet
- Impact report card
- Article/newsletter cover
- Page cover and logo safe masters
- 9:16 vertical-video storyboard

LinkedIn currently supports document posts in PPT, PPTX, DOC, DOCX and PDF, with PDF recommended for quality. Keep all pages the same size. The stack therefore treats SVG as the editable master and PDF as a distribution format.
