# HSF Image-First Storytelling System

## Principle
HSF designs should not look like UI cards with a photo attached. The photograph is the story surface. Text exists to make the image understandable, credible and useful.

## Recommended visual ratio
- Image: 55-80%
- Narrative/evidence: 15-40%
- Brand/support elements: 5-10%

## 14 story archetypes
1. Editorial Photo Story - hero photo + editorial narrative.
2. Human Moment - near-full-frame photo + minimal copy.
3. Field Story - location/date + field image + context.
4. Evidence Story - human image + verified number.
5. Quote Story - portrait/photo + authentic voice.
6. Photo Essay - multi-image mosaic.
7. Before/During/After - three-stage visual documentation.
8. Event Story - event image + context and participation.
9. Institutional Memory - then/now, archive/current, anniversaries.
10. Impact Journey - context -> response -> result.
11. Report Insight - image + evidence + learning.
12. Observance Story - observance + HSF relevance.
13. Practical Guide Photo - image + concise action steps.
14. Call to Action Photo - human image + specific next step.

## Social Plan mapping
- CORE P01-P48: issue/resolution can select any archetype appropriate to the message.
- OBS: Observance Story, Report Insight, Practical Guide.
- HSF: Institutional Memory, Editorial Photo Story, Photo Essay.
- FIELD: Field Story, Photo Essay, Evidence Story, Human Moment.
- EVENT: Event Story, Photo Essay, Before/During/After.
- MOMENT: Human Moment.

## Safeguarding
The storytelling engine does not weaken the existing safeguarding rules. Consent, dignity, privacy, medical/student-record protection and contextual sensitivity remain mandatory.
