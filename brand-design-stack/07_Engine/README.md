# HSF Storytelling Generator

Run from the stack root:

```bash
pip install -r 07_Engine/requirements.txt
python 07_Engine/generate.py 08_Examples/Foundation_Day_Reference/content.yml --out generated/foundation-day
```

The generator embeds supplied photographs into portable SVG outputs, applies focal-point cropping, adapts typography, and can generate platform singles, carousel sequences, LinkedIn PDF documents and 16:9 slide-story PDFs.

SVG remains the editable master. PNG/PDF are publishing derivatives.
